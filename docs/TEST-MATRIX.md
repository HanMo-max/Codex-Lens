# 测试矩阵

桌面组件与状态栏胶囊共用主程序的只读额度刷新流程，但支持的显示窗口不同。自动化结果与安装、签名、真实账号验证分别记录。

| 范围 | 场景 | 预期 | 当前验证 |
| --- | --- | --- | --- |
| 前端 | 格式化与快照合并 | 正确格式化、失败时保留旧值 | 2026-10-08：Vitest 9 项通过 |
| 前端 | TypeScript 与 Vite 构建 | 成功生成浏览器资源 | 2026-10-08：构建通过 |
| Rust | 额度解析、共享快照、刷新调度、胶囊状态 | 不猜测数据，正确处理手动与周期刷新 | 2026-10-08：23 项测试通过 |
| 胶囊 | 五小时窗口与周窗口同时存在 | 只使用有效五小时窗口 | Rust 单元测试通过 |
| 胶囊 | 只有周窗口或五小时窗口不可用 | 不用周额度替代五小时额度 | Rust 单元测试通过 |
| 胶囊 | 刷新失败、过期、刷新中 | 保留最近有效值并显示对应状态 | Rust 单元测试通过 |
| 胶囊 | 倒计时与百分比 | 处理整小时、分钟、重置边界和 0–100% | Rust 单元测试通过 |
| 胶囊 | 全宽点击及宽度变化 | 不同位置点击均可打开/关闭详情 | 2026-10-08：原生 harness 4 次点击通过，覆盖 155px / 199px 宽度 |
| 桌面组件 | 五小时与周窗口 / 仅周窗口 | 小、中尺寸按实际可用窗口显示 | 提供 WidgetKit Preview fixture；本次未重新验收实机 |
| 签名整合 | 主应用与嵌入扩展 | 同一 Team、同一 App Group，Widget Gallery 可添加 | 本次未重新打包或安装验收 |
| 真实数据 | Codex 登录、401/403/429、断网 | 安全错误状态，不暴露凭据，不伪造额度 | 本次未读取真实账号；解析和状态单元测试不能代替实机验证 |
| 生命周期 | 启动、每分钟同步、唤醒、重开 | 胶囊更新，成功快照请求 WidgetKit reload | 调度单元测试通过，完整实机流程需单独验收 |
| 操作 | 手动刷新、开机启动、退出 | 点击入口调用对应操作 | Rust 动作映射通过；系统开机启动行为需单独验收 |
| 跨平台 CI | Windows / macOS Universal | Tauri 构建通过 | 以对应 GitHub Actions run 的实际结果为准 |

## 运行方式

```bash
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
cargo check --manifest-path src-tauri/Cargo.toml
scripts/check-status-popover.sh
```

原生点击检查使用 fixture，不触发真实额度查询。普通 macOS Tauri 构建不会自动嵌入 WidgetKit 扩展，不能将它的 CI 成功视为桌面组件签名整合安装通过。
